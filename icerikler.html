Araçlar

Aşağıda yazılım geliştirme sürecinde sık kullanılan beş araç yer alıyor. Her kart aracın ne işe yaradığını, hangi kategoride olduğunu ve bir örnek görevde nasıl kullanılabileceğini gösterir. Aradığınız aracı bulmak için başlığa göre arama yapabilirsiniz.

Başlığa göre ara

5 sonuç gösteriliyor

Aramanızla eşleşen araç bulunamadı. Farklı bir kelime deneyin.

  • Visual Studio Code

    Microsoft tarafından geliştirilen, eklentilerle genişletilebilen ücretsiz bir kod editörüdür.

    Kategori: Kod editörü

    Kullanım alanı: HTML, CSS ve JavaScript dosyalarını yazıp düzenlemek

  • Git

    Dosyalarınızın değişiklik geçmişini tutan ve farklı sürümlere dönmenizi sağlayan bir sürüm kontrol sistemidir.

    Kategori: Sürüm kontrolü

    Kullanım alanı: Her değişikliği commit olarak kaydetmek

  • Figma

    Tarayıcı üzerinden çalışan, arayüz tasarımı ve prototip hazırlamak için kullanılan bir araçtır.

    Kategori: Arayüz tasarımı

    Kullanım alanı: Bir web sayfasının yerleşimini kodlamadan önce çizmek

  • Postman

    Web servislerine istek gönderip yanıtları incelemek ve bu istekleri test etmek için kullanılan bir araçtır.

    Kategori: API test aracı

    Kullanım alanı: Bir veri adresine GET isteği gönderip dönen JSON yanıtını okumak

  • Trello

    Görevleri kartlar halinde sütunlara yerleştirerek ilerlemeyi takip etmeyi sağlayan bir proje yönetim panosudur.

    Kategori: Proje yönetimi

    Kullanım alanı: Bir ödevin yapılacaklar, yapılıyor ve tamamlandı listelerini tutmak

Araçlar birlikte nasıl kullanılır?

Küçük bir web sitesi yaparken bu araçlar genellikle sırayla kullanılır. Önce Figma ile sayfanın yerleşimini çizersiniz. Ardından Visual Studio Code içinde HTML, CSS ve JavaScript dosyalarını yazarsınız. Her çalışan aşamadan sonra Git ile bir commit kaydı oluşturursunuz. Sayfa bir veri servisi kullanıyorsa Postman ile istekleri deneyip yanıtları kontrol edersiniz. Bütün bu adımları ise Trello panosunda takip edebilirsiniz.

Kart bilgileri nasıl okunur?

Kategori, aracın hangi iş grubuna girdiğini gösterir. Kullanım alanı ise aracın gerçek bir görevde nasıl kullanılacağını anlatır. Bir aracı seçmeden önce bu iki bilgiye bakmak, o aracın ihtiyacınıza uyup uymadığını anlamanın en hızlı yoludur.
